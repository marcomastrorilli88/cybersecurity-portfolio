### Linux Commands Practiced

- `ssh` – Connecting to remote Linux systems
- `pwd` – Displaying the current directory
- `ls -la` – Listing files, including hidden files
- `cd` – Navigating directories
- `cat` – Reading file contents
- `file` – Identifying file types
- `find` – Searching files using specific criteria
- `grep` – Searching for text inside files
- `sort` – Sorting lines of text
- `uniq -u` – Displaying lines that occur only once
- `|` – Passing command output to another command
- `2>/dev/null` – Redirecting error output
